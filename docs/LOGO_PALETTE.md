# Digitory — Color Variables (RGB)

This file lists the primary site color variables (hex + RGB) and a concise note about where each is used on the site.

- `--bg: #fdfdfb` — RGB(253, 253, 251)
  - Use: page background, large-area neutral background.

- `--surface: #ffffff` — RGB(255, 255, 255)
  - Use: cards, panels, lists, and content surfaces.

- `--ink: #0f1c20` — RGB(15, 28, 32)
  - Use: primary text (headings, body), wordmark fallback, high-contrast copy.

- `--muted: #5a6466` — RGB(90, 100, 102)
  - Use: secondary text, captions, form placeholders.

- `--border: #e7e7e0` — RGB(231, 231, 224)
  - Use: borders, separators, subtle dividers.

- `--accent: #1bb3a8` — RGB(27, 179, 168)
  - Use: primary accent color — primary buttons, primary links, important badges; also used as a main hue in the logo mark.

- `--accent-2: #ff8a5b` — RGB(255, 138, 91)
  - Use: secondary accent — highlights, warnings, warm highlights; used as an accent stop in marketing artwork and logo gradients.

- `--accent-3: #f6c945` — RGB(246, 201, 69)
  - Use: tertiary accent — badges, micro-interactions, subtle emphasis.
